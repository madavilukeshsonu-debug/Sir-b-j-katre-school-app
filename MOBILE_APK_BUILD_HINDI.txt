मोबाईलवरून APK बनवण्याची मार्गदर्शिका

महत्त्वाचे: यह प्रोजेक्ट शुरुआती प्रोटोटाइप है। इसमें अभी असली database, secure login और payment gateway नहीं हैं। यह प्रक्रिया APK build करने के लिए है, पूर्ण school management system तैयार करने के लिए नहीं।

1. ZIP फाइल को डाउनलोड करके फोन में रखें।
2. Chrome में github.com खोलें और GitHub account बनाएं/लॉगिन करें।
3. नया repository बनाएं; नाम रखें sir-b-j-katre-school-app।
4. ZIP को फोन में Extract करें। Extract की गई सभी फाइलें repository में upload करें। ध्यान दें: .github/workflows/build-apk.yml भी upload होनी चाहिए।
5. Repository में Actions टैब खोलें। अगर अनुमति मांगे तो workflows enable करें।
6. “Build Android APK” workflow चुनें और “Run workflow” दबाएं।
7. Build सफल होने पर workflow run खोलें। नीचे “Artifacts” में sir-b-j-katre-school-apk डाउनलोड करें।
8. Artifact ZIP को फोन में Extract करें। app-release.apk पर टैप करके install करें। Android अगर अनुमति मांगे तो केवल अपनी बनाई हुई APK के लिए “Install unknown apps” अनुमति दें।

समस्या आए तो Actions में build log का लाल error text साझा करें।

नोट: GitHub की वेबसाइट/बटन का रूप बदल सकता है। APK बनाने के लिए इंटरनेट जरूरी है।
